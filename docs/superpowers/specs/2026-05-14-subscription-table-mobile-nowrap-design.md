# 청약 상세 테이블 모바일 줄바꿈 정리

날짜: 2026-05-14
스코프: `frontend/pages/subscription/[id].vue` 의 데이터 테이블 5개

## 문제

청약 상세 페이지의 데이터 테이블에서 좁은 모바일 폭(360~414px)일 때 셀
내부 텍스트가 글자/단어 단위로 줄바꿈되어 시인성이 떨어진다. 특히 `면적별
공급정보`, `면적별 특별공급 내역` 에서 두드러진다.

각 테이블은 이미 `overflow-x-auto` 래퍼로 감싸져 가로 스크롤 가능 상태지만,
현재 셀 내부에 `whitespace-nowrap` 가 없어 좁은 화면에서 컬럼 폭이 자동으로
줄어들면서 헤더/값이 wrap된다.

## 결정

다섯 테이블 `<table>` 요소에 일관적으로 `whitespace-nowrap` 클래스 추가.

```diff
- <table class="w-full text-sm">
+ <table class="w-full text-sm whitespace-nowrap">
```

## 대상

| 라인 | 섹션 |
|---|---|
| 168 | 면적별 공급정보 |
| 213 | 면적별 경쟁률 |
| 243 | 당첨 가점 분석 |
| 276 | 면적별 특별공급 내역 |
| 308~ | 특별공급 신청현황 |

## 결과

- 헤더/셀이 한 줄 유지. 글자 단위/단어 단위 줄바꿈 둘 다 차단.
- 컬럼 폭이 부족하면 기존 `overflow-x-auto` 가로 스크롤로 처리.
- 가격 셀(이미 nbsp 적용)과 일관된 동작.
- 정보 손실 없음. SEO/구조화 데이터 영향 없음.

## 검증

- frontend vitest run 전체 통과
- 모바일 viewport(375px, 414px)에서 5개 테이블 시각 확인
  - 각 셀이 한 줄에 유지되는지
  - 가로 스크롤이 자연스럽게 작동하는지

## 비-목표

- 모바일 카드 레이아웃 변환은 별도 작업 (정보 손실 없는 nowrap 우선)
- 컬럼 우선순위 축약/펼치기 UI 별도
- 다른 페이지 테이블은 본 변경 범위 밖
