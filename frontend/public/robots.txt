# Nuxt _payload.json 은 SSR HTML 의 중복 데이터(종종 HTML 보다 큼). 크롤만 차단해 크롤 예산을
# 본문 HTML 색인에 집중시킨다. 브라우저 클라이언트 네비게이션은 robots 영향을 받지 않는다.

Disallow: /*_payload.json
Disallow: /admin
# wifi 상세(/wifi/wifi-) 는 영구 noindex 라 색인된 적이 없다(색인 제거가 아니라 처음부터 미색인).
# 따라서 noindex 재확인용 크롤을 유지할 이유가 없어, 재크롤 예산 낭비를 막기 위해 상세 URL 을 크롤 차단한다.
# 카테고리 허브 /wifi 와 지역 wifi(/[city]/[district]/wifi)는 계속 크롤·색인 허용한다.
# sitemapPolicy.ts 에서 wifi 상세 URL은 계속 sitemap 제외 대상이다.
Disallow: /wifi/wifi-
